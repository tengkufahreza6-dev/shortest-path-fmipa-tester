# FMIPA Map — Navigasi Shortest Path UNIMED

Sistem pencarian rute terpendek di area FMIPA Universitas Negeri Medan berbasis graf dan algoritma Dijkstra.

## 🎯 Fitur Utama
- 🗺️ Peta interaktif area FMIPA
- 🧭 Pencarian rute terpendek antar 12 gedung
- 🏢 Database 672 ruangan dari 12 gedung
- 🔍 Pencarian ruangan (nama / kode / gedung)
- 📏 Estimasi jarak & waktu tempuh
- 🎬 Animasi rute
- 📸 Export peta rute sebagai gambar PNG

## 🚀 Cara Pakai
1. Pilih gedung asal dan tujuan dari dropdown, ATAU
2. Cari ruangan via search box → klik "Jadikan Awal/Tujuan"
3. Klik tombol "Cari rute"
4. Rute optimal akan ditampilkan di peta

## 🛠️ Teknologi
- HTML + Tailwind CSS
- Leaflet.js (peta)
- Dijkstra (algoritma rute terpendek)
- GeoJSON (data graf)
