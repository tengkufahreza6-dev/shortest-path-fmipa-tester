# FMIPA Map — Navigasi Shortest Path UNIMED

Sistem pencarian rute terpendek di area FMIPA Universitas Negeri Medan berbasis **graf** dan **algoritma Dijkstra**.

## Fitur
- 🗺️ Peta interaktif (Leaflet.js)
- 🧭 Pencarian rute terpendek antar gedung
- 🏢 Informasi 672 ruangan dari 12 gedung
- 🔍 Pencarian ruangan (nama / kode)
- 📏 Estimasi jarak & waktu tempuh

## Cara Pakai
1. Pilih gedung asal
2. Pilih gedung tujuan
3. Klik "Cari rute"

## Teknologi
- HTML + Tailwind CSS
- Leaflet.js (peta)
- Dijkstra (algoritma rute)
- GeoJSON (data graf)
